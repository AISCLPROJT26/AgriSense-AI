AgriSense AI is a smart farming assistant designed to help farmers make better decisions using artificial intelligence, environmental data and modern technology.

🌾

What is AgriSense AI?

AgriSense AI is a web-based smart farming application that provides useful agricultural assistance through simple and easy-to-use tools.

The system can recommend suitable crops based on soil and environmental conditions, analyze plant images for possible diseases, provide current weather information and maintain a history of farming activities.

🤖 KEY FEATURES

What can AgriSense AI do?

🌾

Crop Recommendation

Suggests a suitable crop using soil nutrients and environmental conditions.

🌿

Disease Detection

Uses a trained machine learning model to analyze plant images and identify possible diseases.

🌦️

Weather Information

Provides weather conditions such as temperature, humidity, wind speed and weather description.

📋

Activity History

Stores previous farming activities and results so they can be viewed later.

⚙️

Technology Behind the Project

AgriSense AI is developed as a Python-based web application using Flask. Machine learning techniques are used for crop recommendation and plant disease detection.

🐍 Python 🌐 Flask 🤖 Machine Learning 🗄️ SQLite 🌦️ Weather API
🎯 PROJECT PURPOSE

Making farming decisions simpler.

The main purpose of AgriSense AI is to demonstrate how artificial intelligence and digital technology can be applied to agriculture.

The project focuses on creating a simple interface where useful farming information can be accessed from a single platform.
